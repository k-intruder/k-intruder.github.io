주간 업무 대시보드

주간 업무 보고를 편집자는 웹에서 수정·Commit하고, 의사결정자는 읽기 전용으로 확인하고 PDF로 받아보는 대시보드입니다. 보고서는 주차별 JSON 파일로 비공개 GitHub 저장소에 쌓여 이력이 남습니다.

데모 열기

구성

  • Cloudflare Access: 사이트 전체를 허용된 이메일 2개로만 열람 제한 (OTP/MFA)
  • Pages Functions (functions/api/[[path]].js): Access JWT의 서명·발급자·AUD·만료를 서버에서 검증하고 편집자/조회자 역할을 나눔
  • GitHub Contents API: 서버에만 있는 최소 권한 토큰으로 data/YYYY-MM-DD.json, data/index.json을 읽고 Commit
  • SHA 비교로 동시 수정 충돌(409)을 감지해 덮어쓰지 않음
  • 지난 주차 대비 상태·진행내용 변경을 자동 비교, 인쇄용 레이아웃으로 PDF 저장

데모 안내

이 페이지는 GitHub Pages라 서버 기능이 없습니다. 데모는 가상의 샘플 데이터(demo/reports.json)로 동작하며, 업무 추가·수정·저장은 현재 탭의 메모리에만 반영됩니다. 실제 보고 데이터는 이 저장소에 포함하지 않습니다.
