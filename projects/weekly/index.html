주간 업무 대시보드

주간 업무 보고를 편집자는 웹에서 수정·Commit하고, 의사결정자는 읽기 전용으로 확인하고 PDF로 받아보는 대시보드입니다. 보고서는 주차별 JSON 파일로 비공개 GitHub 저장소에 Commit되어 이력이 남고, 다른 기기에서 저장한 내용은 자동으로 반영됩니다.

대시보드 열기

구성

  • GitHub Contents API: 브라우저에서 비공개 저장소의 data/YYYY-MM-DD.json, data/index.json을 직접 읽고 Commit
  • 접근 제어: 저장소 단위 fine-grained 토큰으로 편집자(Read and write)와 조회자(Read-only)를 구분. 토큰 없이는 보고서를 읽을 수 없음
  • 실시간 반영: 데이터 경로의 최신 커밋을 ETag 조건부 요청으로 확인해, 새 주차 생성·수정이 다른 기기에 자동으로 나타남
  • 다음 주 보고 생성: 지난 주 내용을 복사해 새 파일과 주차 목록을 바로 Commit
  • SHA 비교로 동시 수정 충돌을 감지해 덮어쓰지 않음, 지난 주차 대비 변경사항 자동 비교, PDF 인쇄
  • 같은 화면을 Cloudflare Pages + Access + Pages Functions로도 배포 가능 (functions/api/[[path]].js)

사용 방법

대시보드를 열고 GitHub 토큰에 보고서 저장소(k-intruder/weekly-data) 권한이 있는 토큰을 입력합니다. 토큰은 그 브라우저에만 저장되며, 보고 데이터는 이 공개 저장소가 아니라 비공개 저장소에만 있습니다.
